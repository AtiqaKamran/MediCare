# MediCare - Patient Health Assistant

MediCare is a web-based patient health assistant designed to help users manage their personal health information, explore symptoms, and access general health guidance through a simple and user-friendly interface.

The project is currently under development, with additional features, improvements, and modules planned for upcoming updates.

## Project Overview

MediCare aims to make basic health information more accessible by providing a platform where users can maintain their health profiles, explore symptom-related guidance, and review their saved medical history.

## Current Features

- **User Authentication:** Sign up and log in using Supabase Authentication.
- **Patient Profile:** Manage personal details and health information.
- **Symptom Checker:** Select symptoms and explore general health guidance.
- **Medical History:** Save, access, and review health information stored in the database.
- **Medical Records:** Access medical information through a dedicated section.
- **Language Support:** English and Urdu language options.
- **Theme Customization:** Light and dark mode support.
- **Responsive Interface:** A clean and user-friendly interface designed for different screen sizes.

## Upcoming Modules

MediCare is actively being developed. The following areas may be expanded in future updates:

- Enhanced patient dashboard and health history management.
- Additional patient health profile features.
- Improvements to symptom guidance and the user experience.
- Additional modules and functionality as development progresses.

## Technologies Used

- **React.js** -  User interface development.
- **JavaScript** - Application logic.
- **Tailwind CSS** -  Styling and responsive design.
- **React Router** - Client-side navigation.
- **Lucide React** - Icons.
- **Vite** - Development server and build tool.
- **Supabase** -  Authentication and database services.
- **Local Storage** - Local application data and profile caching.

## Important Disclaimer

MediCare is an educational project developed for learning and demonstration purposes. It provides general health information and is not a substitute for professional medical advice, diagnosis, or treatment. Users should consult qualified healthcare professionals for medical concerns.
